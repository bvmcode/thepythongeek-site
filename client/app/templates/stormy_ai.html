Agentic weather briefing

What you are reading

Though vibe coding is taking over the world, I still like to write my own code. I use Cursor and Codex as assistants, but I know every inch of the code that ships with my name on it. The How Stormy AI Works page takes you through the code, tools, model selection, and AWS infrastructure behind the briefing.

This briefing is an AI-written weather analysis for my hometown of Atco, NJ. The briefing is built from current observations, National Weather Service products, radar, lightning data, and numerical model guidance. Stormy AI gathers those sources, runs deterministic meteorological diagnostics, and asks a language model to turn the evidence into the report below.

This briefing is scheduled to run every hour between 8am and 8pm and then midnight and 2am.
